## How a row is decided

- **A get-method is reached** when a spec calls the wrapper method whose body does
  `provider.get('<name>', …)`, or names the get-method as a string literal (a direct
  `runGetMethod`). Wrapper method names are listed so a `NONE` row is actionable.
- **A message arm is reached** when a spec calls the wrapper `send*` method that stores
  that arm's opcode first in the message body.
- **`C2C`** means the arm has no wrapper send method at all: only another contract can
  drive it. That is normal and correct for internal protocol messages — but note what
  it does **not** claim. A `C2C` row is *not* evidence the arm is exercised; it says the
  arm is unreachable from TypeScript, so whether any flow test walks it has to be
  established by reading the flow, which is Track B's job, one contract per iteration.
- **`NONE`** is the gap class: no wrapper send method **and** no contract sends it, or a
  get-method no test ever calls.
- Names in _italics_ are non-spec files (helpers, genesis scripts) — they exercise the
  path, but they are not assertions.
