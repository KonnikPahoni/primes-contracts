# Wire-format census

Generated by `node tools/audit-surface.mjs` against `shared/opcodes.ts`,
`shared/schemas/*.tlb`, `contracts/contracts/*.tolk` and every TypeScript send site
(wrappers, shared/messages.ts, tests, scripts, backend, webapp, bot) at commit `b78806a46` (2026-11-24).
**Measurement only.**

## Methodology

- **Handled by** — a contract whose `onInternalMessage` dispatch has an arm for the
  struct carrying this opcode.
- **Sent by (C2C)** — a contract that declares and constructs the struct without
  handling it.
- **TS senders** — count of TypeScript files that reference the opcode, either as its
  hex literal or via a `shared/opcodes.ts` name (`NS.name`). Wrappers, `shared/messages.ts` (the builders the wrappers and the webapp share, G61), tests, scripts,
  backend, webapp and bot are all in scope.
- **Classification** — `Live` (handled + a TS sender), `Live (C2C only)` (handled, and
  the only sender is another contract — normal for internal protocol messages),
  `Defined-never-sent` (a handler with no sender anywhere), `Sent-never-handled` (a
  sender with no handler — would bounce on chain, the serious class), or
  `Registry-only` (declared in `shared/opcodes.ts` or a `.tlb` with neither).
